# UnitFlow ERP — Factory Operations Demo

UnitFlow is a multi-factory manufacturing ERP demo built with Next.js. It showcases production, inventory, orders, invoices, payments, purchasing, client ledgers, accounting, staff permissions, and internal communication.

For backend migrations, deterministic demo seed data, login credentials, and Render/Vercel configuration, see [the demo setup guide](../babanamak-backend-latest/DEMO_SETUP.md).
